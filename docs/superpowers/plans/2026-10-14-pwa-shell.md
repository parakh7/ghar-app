# PWA Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the web app installable and load instantly offline, with a dedicated "you're offline" page for navigations that genuinely can't be served.

**Architecture:** Add `vite-plugin-pwa` to `apps/web` using its `injectManifest` strategy (a hand-written service worker at `src/sw.ts` using `workbox-precaching` + `workbox-recipes`'s `offlineFallback()` recipe) rather than the default `generateSW` strategy. This is a deliberate choice: `generateSW`'s declarative `navigateFallback` option serves its fallback page for *every* unmatched navigation unconditionally (online or offline), which would break a plain page refresh on any deep link (e.g. `/bills/abc123`) even when the network is fine. `workbox-recipes`'s `offlineFallback()` instead tries the network first for navigations and only serves the offline page when the network genuinely fails — exactly the behavior the spec calls for. Icons are generated from the existing `public/icon.svg` by `@vite-pwa/assets-generator` as a `prebuild` step, so no new hand-maintained binary asset is added to the repo.

**Tech Stack:** `vite-plugin-pwa`, `@vite-pwa/assets-generator`, `workbox-precaching`, `workbox-recipes` (new devDependencies in `apps/web`). Vite 8.3.1 and `@vitejs/plugin-react` ^6.1.1 are already in use.

## Global Constraints

- Manifest `theme_color`: `#C2410C` (matches the existing light-mode `<meta name="theme-color">` in `apps/web/index.html`).
- Manifest `background_color`: `#FAF7F2` (the `--paper` design token — see `apps/web/src/styles/tokens.css:16`).
- Manifest `name`: "Ghar — household manager". `short_name`: "Ghar". `display`: `"standalone"`. `start_url`: `"/"`.
- Service worker auto-updates silently (`registerType: "autoUpdate"`) — no user-facing update prompt.
- No custom "Install app" button — rely on native browser install UI only.
- No API response caching in this spec — only static build assets are precached.
- **Flagged risk:** Vite 8.3.1 is newer than this plan's author has verified `vite-plugin-pwa` against. Task 2 Step 1 is a compatibility check before any other Task 2 work — if `npm install` or the subsequent build surfaces a peer-dependency conflict or runtime incompatibility, stop and report back rather than downgrading Vite or forcing the install.

- [ ] **Step 2: Write the service worker**

```typescript
// apps/web/src/sw.ts
import { precacheAndRoute } from "workbox-precaching";
import { offlineFallback } from "workbox-recipes";

declare const self: { __WB_MANIFEST: Array<{ url: string; revision: string | null }> };

precacheAndRoute(self.__WB_MANIFEST);

offlineFallback({ pageFallback: "/offline.html" });
```

`self` is declared locally with only the field this file actually uses, rather than typed as the full `ServiceWorkerGlobalScope` — this file is a module (it has imports), so the local `declare const self` shadows the ambient DOM `self` just within this file, avoiding a conflict with `apps/web/tsconfig.json`'s `"lib": ["ES2023", "DOM", "DOM.Iterable"]` (which has no `WebWorker` lib) without needing a separate tsconfig for this one file.

- [ ] **Step 3: Wire the plugin into Vite config**

In `apps/web/vite.config.ts`, add the import and the plugin entry:

```typescript
import { VitePWA } from "vite-plugin-pwa";
```

Replace `plugins: [react()],` with:

```typescript
  plugins: [
    react(),
    VitePWA({
      strategies: "injectManifest",
      srcDir: "src",
      filename: "sw.ts",
      registerType: "autoUpdate",
      injectManifest: { globPatterns: ["**/*.{js,css,html,svg,png,ico,woff2}"] },
      includeAssets: ["icon.svg", "favicon.ico", "apple-touch-icon-180x180.png", "maskable-icon-512x512.png", "pwa-64x64.png"],
      manifest: {
        name: "Ghar — household manager",
        short_name: "Ghar",
        description: "Househelp, attendance, bills and reminders for your home — in one place.",
        theme_color: "#C2410C",
        background_color: "#FAF7F2",
        display: "standalone",
        start_url: "/",
        icons: [
          { src: "pwa-192x192.png", sizes: "192x192", type: "image/png" },
          { src: "pwa-512x512.png", sizes: "512x512", type: "image/png" },
          { src: "maskable-icon-512x512.png", sizes: "512x512", type: "image/png", purpose: "maskable" },
        ],
      },
    }),
  ],
```
